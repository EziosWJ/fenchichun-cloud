## 3. 从创建流转单开始的完整操作

1. 云端管理端用 `store01` 登录，进入“流转单”，登记新车牌（例如 `晋A66666`）、厂区 `SITE01`、粮种“高粱”、供应商“上海福里希尔食品有限公司”。
2. 用 `lab01` 登录，进入“化验单”，为该流转单录入水分、杂质并确认接收。**化验必须在首磅前完成。**
3. 称重台用 `admin` 登录，进入称重工作台：
   - Agent 模拟器设置首次毛重，例如 26 吨：`POST http://127.0.0.1:8090/api/control`，body `{"action":"up","weight":"26.000"}`，再发 `{"action":"stable"}`。
   - 输入车牌并确认车辆。
   - 工作台按车牌查询云端流转单；唯一可关联时显示“完全匹配”，多张时必须人工选择。
   - 选择流转单后自动带出方向、物料、供货方和司机。
   - 采集重量，核对后确认首磅。
4. 回到云端管理端，用 `store01` 打开该流转单：
   - 首磅后、回磅前，确认实际卸货地点 `1号仓`。
   - 这一步是云端自动关联磅单的前置条件，不能在回磅之后才补。
5. 称重台办理回磅：
   - Agent 模拟器改为皮重，例如 10 吨，并设为稳定。
   - 输入同一车牌，打开待回磅任务，采集重量。
   - 核对弹窗会显示云端流转单、化验单、水分/杂质，并自动带入扣减项。
   - 核对净重调整后确认回磅并出单。
6. 称重台等待或前往“单据同步”确认磅单已上传。同步成功后会自动调用云端关联接口，绑定表状态由 `ticketed` 变为 `linked`。
7. 云端 `store01` 在流转单的“关联正式磅单”中核对并点击“确认过磅单关联”；未确认前不能开具出门证。
8. 云端 `store01` 在流转单下开具出门证并审批。
9. 云端 `guard01` 在出门证/出厂核验中确认实际出厂。

## 4. 快速核对点

- 称重台 `wb_trip_binding`：首磅后状态 `bound`，回磅后 `ticketed`，云端确认后 `linked`。
- 云端 `grain_trip.ticket_id`：自动关联后指向 `wb_cloud_ticket.id`。
- 云端 `grain_trip.ticket_confirmed_at`：库管点击“确认过磅单关联”后写入；未确认不能开证。
- 云端磅单详情可看到实际净重、扣减后重量和多项净重调整明细。
- 称重台单据详情和运输任务详情可回查流转单、化验单、云端磅单号和关联状态。

## 5. 常见问题

- **云端查不到流转单候选**：确认厂区编码同为 `SITE01`、车牌一致、化验已确认接收、流转单未关联其他磅单。
- **回磅后没有自动关联**：确认云端已确认卸货，且化验生效早于首磅、首磅早于卸货、卸货早于回磅；不满足时绑定保持 `ticketed` 并重试。**卸货必须在首磅后、回磅前确认，回磅后再补确认会因“回磅早于卸货”而无法关联。**
- **磅单上传冲突**：本地开发库曾出现 `wb_cloud_ticket` 主键序列落后，已修正。若重建开发库，需保证序列与已有单据一致。
- **扣减类别显示停用**：确认云端类别编码与称重台字典一致；当前支持 `WATER`、`IMPURITY`、`OTHER`。

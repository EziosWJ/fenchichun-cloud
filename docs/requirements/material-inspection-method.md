# 物料检验方式与流转约定

物料基础资料维护检验方式：`lab`（化验）或 `visual`（目测）。现有物料迁移为 `lab`，新增物料默认 `lab`，管理员可根据实际货品维护；木片应配置为 `visual`，不按名称自动推断。

## 接口契约

总部物料列表、保存响应及厂端主数据快照的物料对象增加 `inspectionMethod`。保存物料时接受 `lab` 或 `visual`；未知值拒绝。兼容旧客户端：新建时省略或传 null 默认 `lab`，更新时省略或传 null 保留原值。该字段为主数据的增量扩展，厂端应忽略不认识的字段，不改变现有快照版本。

## 流转规则

登记流转单时按所选物料读取并保存当时的检验方式，后续物料配置变更不影响已有流转单。尚未产生检验或后续业务记录且允许更正物料时，随新物料更新该快照。化验方式沿用现有生效化验单流程；目测方式由库管记录通过或拒收、人员及时间，拒收须记录原因。目测通过后方可继续卸粮、关联磅单和正常出厂；目测拒收由门卫核验后直接退厂，无需磅单和正常出门证。沿用现有岗位权限，后端负责校验。

目测结果确认前须核实供应商；确认后不可覆盖，过程记录保留操作人、时间和说明。目测确认须早于首磅，卸货须位于首磅与回磅之间。现有流转单迁移后保持化验方式。

`POST /api/v1/grain-intake/trips/{id}/record-visual` 使用流转单版本、`conclusion`（`accept` / `reject`）和 `reason`（拒收必填），需要流转单权限。拒收出厂使用既有 `confirm-exit` 的 `rejection` 依据与流转单版本，目测不传化验单 ID。正常出门证的 `inspectionId` 对目测单为 null；生效依据保存在流转单上。

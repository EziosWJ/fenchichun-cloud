# 厂端基础资料同步任务提示词

请在 `/home/wangjian/project/golang/company/weighbridge` 实现厂端“总部基础资料同步”，遵循该仓库 AGENTS.md 和当前业务规格。本任务只做基础资料同步，不实现过磅单上传。

云端接口：`GET /api/v1/weighbridge/sync/master`，使用 `Authorization: Bearer <厂端独立凭据>`。响应为 `{code,message,data}`，只有 HTTP 成功且业务 `code=200` 才算成功。`data` 包含 `schemaVersion=1`、`siteCode`、`scaleCodes` 字符串数组、`categories`、`materials`、`parties`；主体内包含 `contacts`。身份由云端根据凭据返回，厂端必须核对本地厂区编码和地磅编码。具体字段、空值、校验规则和样例以云端仓库 `docs/requirements/weighbridge-sync-api-design.md` 的“完整资料 JSON 字段（版本 1）”为准。

1. 本厂管理员配置云端地址和厂端凭据；首次绑定读取完整资料并核对本地身份。身份不一致、获取或校验失败时不能切换云端资料模式。首次成功后，正式使用期间厂区及地磅编码不再修改。
2. 本地 Server 每小时自动同步，操作员可手动触发一次完整资料同步；两者使用同一逻辑，手动同步不触发单据上传。
3. 完整验证版本、身份、必填字段、编码唯一性、分类引用、主体身份、联系人及默认联系人等；全部资料在一个数据库事务中生效。失败、超时、部分响应或版本不兼容保留上一版，不阻塞本地称重。
4. 总部资料按编码保持本地稳定关联；联系人使用云端稳定 ID。同步不能改写历史业务快照，停用资料对新任务和已首磅任务按现行规格处理。云端模式下禁止本地直接修改总部资料，关闭对应维护入口并在服务端校验。
5. 实现管理员可查看的资料同步日志，记录自动及主动同步时间、结果和失败原因；清空日志不影响资料或同步运行。不要记录凭据。账号授权沿用本厂现有规则。
6. 本次各厂首次正式上线无历史资料导入；不要开发自动匹配、合并或单据上传。真实凭据只放受保护的运行配置，示例使用占位符。
7. 将本仓库 `docs/requirements/cloud-sync-contract.md` 的编码条款与云端同名契约同步：正式使用前可配置或纠正，首次绑定核对身份，正式使用后不再修改。

先核对现有数据表、业务引用、权限和云端契约，按项目结构实现 migration、接口、界面与必要测试。验证首次成功与失败不切换模式、身份不匹配、全量校验或事务失败保留旧版、重复同步保持关联、停用与已首磅任务、断网继续本地业务、定时及手动同步、权限与日志。使用隔离测试数据库，运行仓库要求的后端、前端和数据库检查。完成后说明接口字段、迁移及测试结果，并与云端 agent 联调；不要连接真实业务库。

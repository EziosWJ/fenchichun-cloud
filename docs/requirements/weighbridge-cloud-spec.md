# 云端过磅业务：第一版规格

本文仅记录综合管理大平台中云端过磅业务的已确认目标；云端过磅业务正在开发，厂云端到端同步尚未完成。厂云共同业务边界见[厂云同步契约](cloud-sync-contract.md)，两端同步维护；本次过磅同步涉及的单据字段、业务细则及例外以本地过磅系统有效规格为准。本文不定义平台其他业务的范围或规则。

## 范围

本次各厂正式投入使用时即接入云端，目前各厂尚未使用，本次无需历史资料或单据导入。总部统一维护物料、分类、往来主体和联系人，向所有厂提供完整资料；总部资料维护权限现阶段不讨论。云端以厂区编码核对并归属同步数据，不登记地磅或使用厂端凭据；厂端地磅编码用于本地业务。总部人员可查询所有厂区，不按厂区限制查询范围。

云端接收本厂已出过磅单及约定的重量和联系信息，支持查询和按有效单最终净重统计；作废更新原单，重开形成关联新单。照片、待回磅任务和打印记录保留本厂，云端不修改、作废或重开本厂单据。总部接受同步滞后及原单作废与新单重开之间暂时少计，查询页面提示数据可能尚未同步。

## 验收目标

- 首次绑定和完整资料同步成功后正式使用；每小时及主动同步完整资料，失败不产生部分更新，本厂使用上一版继续正常业务。
- 云端正确校验厂端与厂区绑定，按约定接收单据变化并确认，重复变化不重复出单，同单据变化及关联重开按约定顺序处理。
- 断网出单、作废和重开后可补传；云端按收到的当前有效单及最终净重统计，作废排除，重开不重复统计。
- 关闭同步后的本地资料处理按[厂云同步契约](cloud-sync-contract.md)执行；不开发自动匹配或合并。恢复旧备份后流水号倒退的处理继续暂缓。

基础资料接口见[接口设计](weighbridge-sync-api-design.md)，单据接口细节仍待双方联调；开发依赖和验证顺序见[云端开发准备](weighbridge-cloud-development.md)。

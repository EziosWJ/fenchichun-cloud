# 当前阶段：基础资料完善与独立化验单

2026-11-06，上一阶段已确认并完成的范围记录。后续新增流转关联及出门证见[本轮实现](grain-intake-implementation.md)。本阶段暂不建设流转流程、仓库、库存、入库单、卸粮确认或自动扣减。

- 供应商和粮种复用现有往来主体与物料，不重复建档。供应商补公司信用代码、个人身份证的校验及去重；既有缺证件资料不自动补造，保存供应商时补齐。
- 个人身份证校验18位格式、出生日期及校验位；公司信用代码校验18位字符格式。非空证件由数据库唯一索引防止重复；输入统一去除首尾空白并转大写。个人身份证不返回给列表或保存响应，不加入厂端资料同步；编辑留空保留已登记号码，填入新号码可更正。
- 独立化验单：车牌、粮种、供应商、检测值、人工结论及原因；司机信息随单选填，合同编号选填。水分和杂质为%，容重为g/L，用户已确认单位。
- 草稿允许缺字段，可编辑和删除；正式确认要求车牌、粮种、供应商、三项检测值和结论完整，拒收须原因。水分与杂质范围0至100，容重大于0；技术输入容量为最多6位整数和6位小数，不代表客户验收标准，不计算扣减或自动判定。
- 已确认单不能编辑删除；录错须填写原因作废后另建。复检从已确认单创建关联草稿，只复制送检基本信息，不复制检测值和结论；原单保留，不自动失效，不自动选择最终有效单。
- 列表支持关键词、状态和分页，条件同步到URL；详情保留确认及作废人员时间。关键写操作记录审计，版本冲突拒绝覆盖。
- 新菜单为“化验单”，初始授权ADMIN，可通过现有角色菜单管理授权其他岗位。后端同样检查该菜单授权，不只控制前端入口。

实现入口：`server/internal/laboratory/`、`web/src/pages/laboratory/InspectionsPage.tsx`。API为 `/api/v1/laboratory/inspections`；动作包括confirm、void、delete、retest，Swagger由Handler注释生成。

开发库已执行迁移。后端检查、前端lint/typecheck/test/build及回滚事务数据库验证用于验证本阶段；完整Docker PostgreSQL集成测试需Docker服务可用，不能用回滚验证代替全部集成契约。

后续流转方案见[原粮入厂规格](grain-intake-spec.md)，本阶段不要求先创建流转单，也不自动关联磅单。

# 基础资料与早期化验阶段

## 供应商资料规则

- 供应商和粮种复用现有往来主体与物料。企业统一社会信用代码和个人身份证号码均为选填，供应商新增和编辑时均可留空。
- 个人身份证校验18位格式、出生日期及校验位；公司信用代码校验18位字符格式。非空证件由数据库唯一索引防止重复；输入统一去除首尾空白并转大写。个人身份证不返回给列表或保存响应，不加入厂端资料同步；编辑留空保留已登记号码，填入新号码可更正。

## 早期化验流程

独立建单、草稿、单独确认和复检属于早期方案。现行化验随流转单录入，详细字段、作废和权限见 [原粮入厂当前实现](grain-intake-implementation.md)。早期文档可通过本文件的 Git 历史查阅。

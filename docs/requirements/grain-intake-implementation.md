# 原粮入厂：当前管理端实现

适用于当前云端管理端。原粮一期目标见 [业务规格](grain-intake-spec.md)，现场操作前置条件和放行验收见 [状态流转](grain-intake-state-machine.md)，字段与接口以当前 Handler 和生成的 Swagger 为准。

## 1. 使用方式

1. 库管在“流转单”登记厂区、车牌和粮种；供应商可待核实，司机及合同编号选填。同车再送粮另建一张流转单。
2. 化验员选定待化验的流转单，录入水分（%）、容量（g/L）及接收或拒收结论。拒收需填写原因。每趟只允许一张未作废化验单，提交即生效。符合更正条件时可作废重录，旧结果留档。
3. 目测物料由库管记录通过或拒收，详情见 [物料检验方式与流转约定](material-inspection-method.md)。
4. 现场首磅后，库管记录实际卸粮地点并确认卸粮。磅房在厂端称重、出单和打印，联网后同步正式磅单，再按厂区编码和单号关联流转单。
5. 卸粮已确认、有效磅单已关联后，库管开具出门证，再审批；门卫核验后在实际放行时点击确认出厂。开具、审批和实际出厂分别留存。
6. 化验或目测拒收时，门卫凭有效拒收依据确认实际出厂。拒收退厂使用独立查询入口，已退厂记录可查询。

## 2. 校验与保留规则

- 新建化验单须关联流转单，检测字段提交后保留。水分范围为 0 至 100%，容量须大于零，仅用于检验记录。杂质由磅房回磅时录入。
- 已确认化验、卸粮或磅单会限制登记信息更正。已作废的化验继续保留原始记录。
- 作废化验须提供原因并校验版本。云端已收到符合本趟特征的有效磅单、已开证或已出厂时，作废受阻。作废生效后清空旧依据，可以在允许的阶段重新录入。
- 关联磅单核对其当前厂区归属、入厂方向、车牌、粮种、供应商、有效状态及时间先后。化验生效应在实际首磅之前，现场卸粮确认应在两次称重之间；晚同步保留现场时间，冲突阻断，不自动覆盖。
- 云端不需要先收到首磅回执才能办理现场卸粮确认。首次/二次过磅均不要求先调用云端准备接口，符合本地称重、联网补传方式。
- 同一有效磅单仅能关联一张流转单，同一流转单不能改挂另一张磅单。已关联磅单作废时：尚未开证的流转单自动解除关联、记录系统事件并回到接收待完成，可重新关联重开后的磅单；已开证的流转单显示需核查，阻断审批和正常放行。
- 磅单详情分别展示实际净重（毛重减皮重）与扣减后重量（v3及以上磅单的最终净重）；v2磅单没有扣减后重量，不回退用实际净重冒充。
- 记录版本用于防止并发覆盖。重复确认出厂核对相同历史依据后返回原结果，不重写出厂时间和人员；使用不同依据则拒绝。
- 流转过程记录与通用操作审计在业务事务中提交。化验录入和作废、开证、审批和出厂均可回看。

## 3. 菜单与授权

新增流转单与出门证菜单，初始授权ADMIN，其他岗位通过既有角色菜单管理分配：

| 操作 | 服务端要求 |
| --- | --- |
| 登记、更正、卸粮、关联磅单、开具出门证 | 流转单菜单权限 |
| 录入和作废化验单 | 化验单菜单权限 |
| 审批出门证 | 出门证及流转单菜单权限，供库管使用 |
| 查看核验依据、正常/拒收确认出厂 | 出门证菜单权限，门卫无需流转单管理权限 |

菜单显隐不替代服务端校验。流转单与出门证详情URL同样受其父菜单权限保护。

## 4. API 与代码入口

- `/api/v1/grain-intake/trips`：流转单列表、登记；`/{id}` 查询/更正。
- `/api/v1/grain-intake/trips/{id}/{action}`：明确业务命令，包含目测、卸粮、关联磅单、开证、审批和确认出厂。
- `/api/v1/grain-intake/trips/{id}/ticket-candidates`：查询本趟可关联的正式磅单及不可关联原因。
- `/api/v1/grain-intake/permits`：正常出门证列表。
- `/api/v1/grain-intake/rejections`：拒收退厂及历史查询。
- `/api/v1/grain-intake/exit-basis/{id}`：门卫按流转单核验依据。
- `/api/v1/laboratory/inspections` 支持列表、详情和提交，`/{id}/void` 支持作废。提交须提供 `tripId`，厂区与车辆资料从流转单取值。

后端位于`server/internal/grainintake/`，化验关联约束位于既有`server/internal/laboratory/`；前端位于`web/src/pages/grain-intake/`。没有改变现有磅单同步载荷或摘要规则，也没有替厂端开发新的称重逻辑。

## 5. 厂端协同与扣减

- 厂端流转单查询和幂等关联的字段、错误和前置条件见 [厂云协同接口](grain-intake-collaboration-api.md#7-已实现的流转单查询与关联接口)。
- 扣减规则按物料、类别、版本及生效时间维护。支持按吨固定扣减和按水分比例扣减，厂端按最终毛重减最终皮重折算比例项。扣减管理权限为 `grain-intake:deduction-rules`，目测物料不能启用云端扣减规则。
- `GET /api/v1/grain-intake/deduction-preview` 按物料及水分预览匹配的比例。容量和杂质均不作为云端比例规则的依据。

## 6. 验证与使用限制

开发用例参见 [原粮状态流转和验收场景](grain-intake-state-machine.md#4-验收场景)。隔离 PostgreSQL、磅房真实联调和现场通过情况以当次执行记录为准。

磅房离线取得化验依据的方式仍待落实。正常放行以云端有效依据为准，磅房已知有作废或重开待同步时须通知门卫暂缓。已开证后因磅单作废进入核查状态的恢复方式仍需另行明确。
